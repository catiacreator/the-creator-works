# Fontes

Já aqui estão a **Inter 400 e 700** (licença SIL Open Font, em
`Inter-LICENSE.txt`), para a app funcionar mal a instales.

Substitui-as pelas **mesmas fontes que usas no template do Canva**. É isto que faz os
PNGs saírem iguais ao teu desenho original.

Formato do nome do ficheiro:

```
NomeDaFonte-700.ttf
NomeDaFonte-400.ttf
NomeDaFonte-400-italic.otf
```

- `NomeDaFonte` é o que escreves no campo **Fonte** de cada caixa de texto no
  editor de templates.
- O número é o peso (400 normal, 700 negrito).
- Aceita `.ttf`, `.otf` e `.woff` (não aceita `.woff2`).

Se a pasta ficar vazia, a app descarrega a **Inter** como recurso de emergência
para nada rebentar — mas o desenho não vai bater certo com o teu template.

## Onde arranjar as tuas fontes

No Canva, abre o template → tipo de letra usado → procura a mesma família no
Google Fonts (https://fonts.google.com) e descarrega os ficheiros `.ttf`.
Se for uma fonte comprada, usa o ficheiro que recebeste na compra.
